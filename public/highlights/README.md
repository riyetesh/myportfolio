# Highlight images

Replace the square image slots with local JPG files using this convention:

- `profile/1.jpg`
- `education/1.jpg`, `education/2.jpg`, `education/3.jpg`
- `training/1.jpg`, `training/2.jpg`, `training/3.jpg`
- `experience/1.jpg` through `experience/6.jpg`
- `projects/1.jpg` through `projects/4.jpg`
- `scholarship/1.jpg`
- `skills/1.jpg`, `skills/2.jpg`, `skills/3.jpg`
- `leadership/1.jpg` through `leadership/6.jpg`

The story viewer loads these paths automatically. Missing files fall back to the minimal grey square artwork, so the layout remains stable while images are being replaced.
