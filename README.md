# Your Name · Portfolio

A personal portfolio starter built with Next.js, TypeScript, and plain CSS.

## Start locally

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open `http://localhost:3000`

## Personalize it

- Replace **Your Name**, the email address, social URLs, and location in `app/page.tsx`.
- Update the `projects` and `capabilities` arrays at the top of `app/page.tsx`.
- Change site title and description in `app/layout.tsx`.
